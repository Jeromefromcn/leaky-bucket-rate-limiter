# Leaky Bucket Rate Limiter

Single global, in-memory leaky-bucket rate limiter exposed as a small REST API.
The full specification lives in [backend-4.md](backend-4.md).

## Language rule

Every artifact in this repository is written in English: code, identifiers,
comments, Javadoc, test names, assertion messages, README, configuration keys,
sample payloads, commit messages and PR descriptions. No Chinese anywhere in the
repo, including example data.

## Stack

- Java 25 LTS.
- Maven.
- Spring Boot.
